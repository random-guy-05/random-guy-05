# Arnav Mana

I work on machine learning for health: sleep and ICU physiology, single-cell biology and the tools around them.

## Research

- **[sleep-eeg-interface-search](https://github.com/random-guy-05/sleep-eeg-interface-search)**: language-model feature selection for a sleep-EEG foundation model, compared across three hospitals.
- **[PhysioGraph](https://github.com/random-guy-05/PhysioGraph)**: tests whether SpO2 instability is an early warning of cardiogenic decompensation in ICU patients ([physiograph.xyz](https://physiograph.xyz)).

## Virtual Embryo Challenge

- **[vec-toolkit](https://github.com/random-guy-05/vec-toolkit)**: 38 community tools, guides, browser apps and HPC templates for the Virtual Embryo Challenge (NeurIPS 2026), in one repo.

## Tools

- **[LocalLink](https://github.com/random-guy-05/LocalLink)**: native macOS controller for Moonlight, Sunshine and Tailscale remote desktop streaming.
- **[mail-tracker](https://github.com/random-guy-05/mail-tracker)**: self-hosted open and click tracking for Gmail.
- **[image-studio-alignment](https://github.com/random-guy-05/image-studio-alignment)**: dot-grid detection and alignment for ImageStudio.
